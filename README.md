# fantasy-gm-ai

## Overview

**fantasy-gm-ai** is a prototype for a private-use fantasy sports analytics assistant. This project is still in the development phase and is not yet operational.

## Planned Features

- **Read-only Yahoo Sports integration:** The system is designed to pull league data from Yahoo's API in a read-only fashion. No write operations, no automated moves.
- **League-wide scouting:** Generate scouting reports for all players across the league.
- **Waiver and trade recommendations:** AI-driven suggestions for waiver wire pickups and trade analysis.
- **Daily opponent/category forecasts:** Project daily performance based on matchups and statistical categories.
- **Injury and news feeds:** Aggregate injury reports and relevant news to inform lineup decisions.

## Current Status

- **No live Yahoo API connection yet.** The repository contains the project structure and prototype code, but no active data integrations.
- **No automated moves.** All recommendations are intended to be manual; the assistant does not (and will not) make live roster changes.
- **Not yet operational.** This is a prototype and development-in-progress. Expect changes and incomplete features.
